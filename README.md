This is my personal portfolio website as a BTech Artificial Intelligence and Machine Learning student. It showcases my technical skills, projects, learning journey, and interest in backend development, AI, and software engineering.

The portfolio is designed for students, recruiters, internship reviewers, and anyone interested in seeing my practical work.

## How to Use

### For Visitors

1. Open the live website.
2. Explore the introduction and skills sections.
3. Review the projects.
4. Follow the project links to view the implementation and source code.

### For Developers

1. Clone or download this repository.
2. Open `index.html` in a browser.
3. Edit the HTML, CSS, or JavaScript as required.
4. Deploy the updated files using a static hosting service such as Netlify or GitHub Pages.
