# Polite Web Scraper

A small JavaScript scraping pipeline built for the FlyRank internship.

## Target

Books to Scrape — a public practice sandbox designed for learning web scraping.

## Scope

The scraper will process the first three catalogue pages and discover 60 unique book pages.

## Language

JavaScript / Node.js

## Politeness

The scraper will use an identifying User-Agent, a timeout, a delay between real requests, and cached HTML during development.

## Ethics

I will not reuse this code on another site without checking its rules and terms first.
